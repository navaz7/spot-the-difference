# Spot the Difference — Gullwing Harbour

A cosy spot-the-difference game set in a lighthouse-café harbour. Two near-identical scenes sit side by side — boats, gulls, bunting, a café terrace and one very relaxed cat — with 10 differences hidden in each round. Click or tap a difference in either picture to ring it with a marker and hear a chime; the counter tracks how many remain, a timer keeps the pressure gentle (a miss costs 5 seconds), and a limited hint button makes an unfound difference glimmer. Three rounds — Morning, Sunset and First Light — raise the difficulty with subtler changes, smaller targets and less time. Fully keyboard accessible (arrow keys move the probe, Enter checks it, H hints), with all art drawn in code as inline SVG and all sound synthesized with WebAudio — no network, no external assets.
